ROAD TO IRONMAN — Publicação no GitHub Pages
1. Criar repositório público no GitHub.
2. Enviar os ficheiros desta pasta para a raiz do repositório (não enviar apenas o ZIP).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Aguardar a publicação e abrir o endereço indicado pelo GitHub.
5. Para atualizar: substituir index.html e, se necessário, os restantes ficheiros no mesmo repositório.
NOTA: Edições feitas dentro da aplicação são locais ao navegador e não são publicadas automaticamente.
